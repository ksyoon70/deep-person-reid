vsrc_dir 아래는 이미지 파일과 해당 json 파일이 쌍으로 존재하는데, 가끔은 쌍이 아닐 수도 있다.
예를 들어 0081_c1s1_000075_02.jpg 및 0081_c1s1_000075_02.json 이런 식으로 이름이 존재한다.
여기서 '_'로 나뉘어지는 첫번째 부분 위 예에서 '0081' 가 vid가 된다. 이 부분은 언제나 숫자이고 만일 파일명에 vid가 없거나 숫자가 아니면 에러를 print 한다.

vsrc_dir에서 파일 이름을 읽어서 가장 큰 vid를 찾아서 그 값을 veri_max_vid에 저장한다.
veri_max_vid의 100자리 보다 하나큰 숫자를 구하고, 예를 들어 veri_max_vid가 0769이면 그 수는 0800이 된다.
margin = 구한숫자 - veri_max_vid으로 구한다.

kvid = veri_max_vid + margin + 1 부터 시작하고,

src_dir 아래에는 하위 폴더가 많이 있고, 하위 폴더의 이름 구조는 
예를 들어 'K3_GDI_black_001'이면 'K3'는 모델이름 두번째 'GDI'는 상세모델 나머지는 색깔과 숫자이다.
src_dir에서 하위 폴더의 이미지 파일과 json 파일을 vmodel_dir로 복사하는데,
복사할때 src_dir의 원 위치가 있는 폴더에서 '모델'_'상세모델' 형태의 디렉토리를 만들어 그 아래에 복사한다.
복사할때 그냥 복사하지 않고, 이미지파일 이름의 vid부분을 kvid로 바꾸고,

'image_train' 'image_query' 'image_test' 디렉토리를 만들다.
train_ratio = 0.8 query_ratio = 0.15 image_test = 0.05 를 기본으로 배율 만큼을  각 디렉토리로 복사한다.
이 기준은 전체 데이터가 아니라 vmodel 모델이름 폴더 단위로 적용되도록 한다.
복사는 항상 이미지와 json 짝으로 복사하고 짝이 맞지 않으면 error print를 한다.
만일 각 비율로 나눗었을 때 파일 쌍(이미지, json)의 갯수가 1개 이하 소숫점이면 정수로 바꾸고, ratio가 0이면 복사하지 않는다.
'image_test'의 복사를 가장 먼저하고 복사 갯수가 0이면 하지 않고, 소숫점 이하면 'image_query' 복사할 것을 하나 줄이고 그것을 'image_test'에 복사한다.
동일하게 'image_query'에 동일한 규칙이 적용되고 갯수가 1개 미만 소숫점이면 'image_train'에 복사할 것을 하나 줄이고, 'image_query'에 복사한다.
마지막으로 'image_train'에 복사한다.
